Guide

One place for your coacervation and conditioning work: plot %T coacervation curves and AUC, map phase diagrams, track Lasentec particle size, and pull formulas and PTL / ILS performance straight from Nexus by Batch ID. New here? The steps below walk through a typical run. Questions? Contact Kyla Fung : fung.k.1@pg.com.

What is this?

A single place to measure coacervation, see particle size and phase behavior, and compare conditioning performance. It does three things:

1 Measure coacervation

Turn a plate's %T dilution series into an Absorbance curve, an AUC (how much coacervate forms) and a fingerprint (onset, peak, width) for every shampoo, clear or opaque.

2 See structure & phase behavior

Overlay Lasentec (FBRM) particle‑size distributions and map phase diagrams (surfactant × polymer) to see where coacervate forms.

3 Compare performance

Type a Batch ID to pull the formula and every test on record from Nexus, and benchmark formulas against each other (PTL combing, ILS sensory, deposition).

Performance Library, explained

Everything here reads PTL (instrument) and ILS (sensory) results straight from Nexus by Batch ID : no uploads needed. Four tools:

Test Comparison

Compare formulas four ways : Batch vs Batch, Ingredient vs Ingredient, Chassis vs Chassis, or By Request. Pick the tests (SACS, DRF, IFF, ILS, deposition) and read average values per parameter with error bars : green = best, red = worst. Export to CSV.

Correlation

Plot any two measurements against each other across all batches (e.g. silicone deposition vs combing friction, or SACS friction vs ILS smooth feel). Get a regression line, R² and n; color the points by chassis to see if the relationship holds.

ILS in‑lab sensory

Pick batches to see the prep conditions plus wet and dry sensory attributes as radar charts and a batch × attribute heatmap : scan many formulas at a glance.

PTL performance test lab

Instrument data: SACS combing (box plots of the replicate spread, dry & wet), DRF rinse‑friction profiles (Initial → Middle → Final), and IFF. Lower = better conditioning.

Key concepts & glossary
Coacervation
The turbid phase that forms as a shampoo is diluted during rinsing, driving polymer/surfactant deposition and conditioning.
%Transmittance / Absorbance
The plate reads %T; we convert to Absorbance (A = 2 − log10%T). Higher absorbance = more coacervate / turbidity.
Dilution (1:X)
How far the shampoo is diluted. X‑axis runs from concentrated (left) to dilute (right).
AUC
Area under the absorbance‑vs‑dilution curve over a chosen window : an overall “how much coacervation” number.
Onset
The dilution where coacervation first rises off baseline.
Peak / trough
The dilution of maximum coacervation (peak absorbance = minimum %T).
Recovery
How fully the curve returns toward baseline on further dilution (strong = droplets re‑dissolve; weak = coacervate persists).
Transition width
How broad the coacervation region is (narrow / moderate / broad).
Fingerprint
The above, plus a heuristic “likely behavior” read‑out. For screening, not a validated performance model.
What you need

For lookups, comparisons and correlations, all you need is a Batch ID : the app pulls the formula, tests and performance straight from Nexus. You only upload files when you are adding a brand‑new %T coacervation run (a raw .txt plate plus its input sheet), which you do in the Manage data tab.

AUC comparison

      

        How the AUC is calculated: each well's %T (transmittance) is converted to
        absorbance, A = −log10(%T/100). As a shampoo is diluted and coacervate
        forms, the solution gets turbid, so absorbance rises in proportion to how much coacervate is
        present (Beer–Lambert). We fit absorbance vs. dilution and take the area under that curve
        (AUC) — a single number for total coacervate formed across the dilution series.
        Total AUC = whole curve; consumer-window AUC = the in-use range (1:1–1:20).
        A larger AUC means more coacervate, which correlates with deposition of conditioning actives
        (silicones, cationic polymers) onto hair — so AUC is a fast screen for deposition potential.

Analysis metrics — precipitated %, strength, mean %T, t95

          
Report-style summary. Precipitated % = wells with %T < threshold. Strength = mean(100−%T) over precipitated wells only (how strongly turbid, not just how many). Mean %T = plate average. t95 = time to converge. Metrics are at the final read (equilibrium); the common-cutoff column snapshots the nearest read to the cutoff for cross-experiment comparison.

        queryable place — the same data workflow used by the AP-precipitation and Ternary-Diagram
        platforms. Uploads append to CoacervationData.csv (well-level curves) and
        CoacervationSamples.csv (per-sample AUC / fingerprint / metadata), tracked by a
        manifest that prevents duplicate uploads. Requires a .env with your Azure
        connection string (see .env.example).

Nexus lookup Databricks

      
Pull sample metadata straight from Nexus by BatchID — the same
        reagent-lookup workflow the Ternary-Diagram platform uses (queries
        cdl_stc_prod.silver_nexus.sdidataitem). Enter BatchIDs (e.g.
        B-20260722-01427), comma or newline separated, or pull every BatchID already in your
        library. Requires DATABRICKS_ACCESS_TOKEN in .env (server-side lookups
        use a token, never a browser popup).

Composition & worksheet Databricks

      
Pull a sample’s composition from the right source automatically:
        internal P&G formulas → EBR as-made batch (via Nexus s_batch →
        silver_ebr.batch_details); competitor products → Mintel INCI + claims
        (groupdb_beauty_di_rd.mintel). Look up by a catalogued product name, or by an internal
        Batch/Sample ID (or an EBR##### reference). Uses the same
        DATABRICKS_ACCESS_TOKEN as Nexus (needs SELECT on cdl_stc_prod &
        groupdb_beauty_di_rd).

Product catalog & tags

      
Catalog any shampoo — in-market P&G products (Herbal Essences Shine
        Brilliance…), competitor products (Odele Clarifying, K18 Peptide Prep Detox, OUAI Detox,
        L’Oréal EverPure Clarify…), benchmarks or controls. Record its
        category, ingredients / formula, and consumer perception (lather, wet
        conditioning feel…). You can add products before you run them, then link plate data later.

Import product data CSV / GNPD export

      
Export a search from Mintel GNPD (or any product sheet) to CSV and upload it
        here. Columns are auto-detected (product, brand, category, claims, ingredients, GTIN) and matched to
        catalogued products by GTIN then name — filling ingredients & claims without touching
        plate links. Unmatched rows can be added as new competitor products.
